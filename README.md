## 📖 O projekcie

**KampusNav** to lekka, responsywna aplikacja internetowa ułatwiająca studentom pierwszego roku oraz gościom uczelni szybką orientację w przestrzeni kampusu. Głównym celem systemu jest **błyskawiczne doprowadzenie użytkownika do wybranego pomieszczenia** (np. sal laboratoryjnych, dziekanatu, auli) bez błądzenia po piętrach i korytarzach.

Aplikacja informuje o kondygnacji, dokładnym opisie dojścia od wejścia głównego, godzinach otwarcia oraz **dostępności architektonicznej** (windy, szerokość drzwi, brak progów). Umożliwia również zgłaszanie usterek infrastruktury (np. awarii windy).
